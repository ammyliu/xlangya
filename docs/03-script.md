# 琅琊阁·锦囊令 三集剧本初稿

状态：讨论稿；目标每集约 2 分 30 秒，未将本稿整体录入 Canvas。原创对白。梅长苏入京后、靖王尚不知其真实身份；蔺晨短暂入京为本番外安排。

## 故事总纲

金陵城外一批赈粮即将运往灾区。有人借琅琊阁发新令牌之机，向靖王和江左盟分别散布假消息，诱使双方在渡口冲突，掩盖侵吞官粮的行为。梅长苏发现旧图与错配时间，众人在 X-engineer 选囊、制器、实测，最终救出押船老吏、保全账箱。

琅琊阁汇集不同模型能力；锦囊各有所长；令牌是授权凭证。推演依赖已有信息，不能预测一切。主题：可以借百家之智，不能把判断交给别人。

## 第一集 七牛送令

### 工坊门前 晨

铜铃轻响，晨雾散开。七头牛四前、三后牵引木车，停在 X-engineer 门前。用穿雾而来的传奇感代替飞天特效。

飞流数牛：“七头。”

蔺晨从车上抱下木匣。飞流：“都是令牌？”

蔺晨：“牌子不重，来求的人可不少。”

飞流伸手，蔺晨举高木匣：“你要它做什么？”

飞流：“给苏哥哥。”

梅长苏在门内：“先让他进来。七头牛都等得住，你倒等不住。”

### 工坊案前 晨

匣内是一排编号不同的令牌，案旁摆着不同纹样的锦囊。

蔺晨：“这批令牌，各有登记。能取哪些锦囊，要看所授的权限。”

飞流比对令牌：“他多。我少。”

蔺晨：“你要护人，他要查案。先拿合用的。”

梅长苏：“令牌是凭证。锦囊才是本事。”

蔺晨：“还有一样，阁里不发。”

梅长苏：“判断。”

### 靖王带信而来

靖王放下一封盖有转运印记的信：“赈粮在青石渡失踪。有人指认，动手的是江左盟。”

飞流：“没有！”

梅长苏示意他稍安，取出另一封密报：“我收到的消息，却说殿下今夜要封渡口，拿江左盟的人。”

靖王：“先生信哪封？”

梅长苏：“两封都不急着信。”

两信并排，来自不同方向却使用相似措辞。

梅长苏：“一个要殿下出兵，一个要江左盟拔刀。”

蔺晨：“倒像有人替两边都想好了。”

### 集尾

飞流从信封中抖出渡口图，标有粮船抵达时辰。

靖王：“这批赈粮，明日才到。”

梅长苏翻图，背面日期有涂改：“有人想让两拨人，提前一夜相遇。”

切黑。

## 第二集 锦囊有界

### 选囊查图 日

飞流抱来一叠锦囊：“都用。”

梅长苏只取一只：“先认清这张图，再算怎么走。”

通过辨图锦囊的图例与方法，对照近期记录，发现来图是去年未改建的旧栈桥。靖王拿出行军图比对。

靖王：“难怪两边都说对方占了渡口。”

梅长苏：“他们说的，根本不是同一个地方。”

再取推演锦囊，放入正确时间、地点与人数。

蔺晨：“若仍照旧图走呢？”

梅长苏推棋至窄桥：“两边相撞，谁先伸手，都会被看作动武。”

靖王：“我立刻传令，先停兵。”

### 真正危险

飞流查探回来，放下锈断铁扣：“桥，松了。”

修缮记录却声称已加固。梅长苏看两封假信：“不是只想让我们争起来。”

靖王：“争起来，便没人看桥，也没人查粮。”

梅长苏：“等桥断了，失掉的官粮，都能记作落水。”

### 全员锻造

飞流安装护腕锁扣并试力；靖王改良剑鞘承力卡环；蔺晨给扇匣加装针具和止血布夹层；梅长苏坐着装配折叠棋盘，更新旧桥位置和撤离路线。器具是本剧新增设计，不是原作装备。

飞流把附件装满护腕，手腕难以转动。

梅长苏：“飞流，抬手。”

飞流费力抬起。梅长苏取下多余附件，只留锁扣：“现在呢？”

飞流握拳：“快。”

梅长苏：“有用的留下。”

### 集尾

试力绳索滑脱，靖王扶住木架。营造尺寸同样取自旧图。

蔺晨：“方法没错。尺寸错了。”

梅长苏换上飞流实测记录：“重做这一处。今夜救人，不能拿‘应当如此’作数。”

远处响起前导船铃。切黑。

## 第三集 同令不同局

### 渡口 暮色

以桥边、船舷、缆绳和水声交代空间，不做大船队。靖王已令双方后退，冲突解除。押船老吏为护住封存账箱，仍困在栈桥外端。

老吏：“账不能丢！”

靖王：“先护住人！”

飞流到达稳定石基，将引绳抛向老人。起落用剪辑完成，不要求长距离连续飞跃。

### 各尽其用

飞流将绳扣入护腕，指导老人系牢；靖王将剑鞘卡环固定于可靠石柱旁组织接应；蔺晨备好救治；梅长苏观察实况，发现桥板倾斜不同于预估。

梅长苏：“别走桥面。飞流，从右侧石阶带他回来。”

飞流改变路线。工具提供方案，人根据现场修正。

### 救人留证

老人脱险，飞流将账箱提绳挂到接应索，众人拖回箱子。仅拍局部木板脱落与绳索骤紧，不做整桥坍塌。

老吏接受包扎，看到假信：“这印是真的，信不是我写的。”

他从账箱取出留底，与假信时间、地点均不一致；修桥款交割记录提供进一步查案线索。

靖王：“原件封存。人，我护送回去。此事一项一项查。”

### 工坊 夜

飞流擦护腕，靖王归剑，蔺晨整理器具，梅长苏将假信放在棋盘旁。

靖王：“他们给了我们两种说法，想换一场争斗。”

梅长苏：“只要我们急着证明自己是对的，便会替他们把局走完。”

蔺晨收囊：“如今知道，哪只最厉害了？”

飞流看护腕磨痕：“合用的。”

梅长苏微笑：“还有，用它的人。”

四枚令牌、不同锦囊与磨损器具特写。片尾提案文案：七牛云 MaaS，一处汇聚，各有所长。令牌对应 API Key，锦囊对应模型能力。X-engineer：把能力锻造成解法。
