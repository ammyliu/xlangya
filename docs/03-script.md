# 两部剧故事与分集设计

## 剧一《麒麟才子》

化名苏哲的梅长苏在 X-engineer 锻造坊重铸赤焰军手环，准备为赤焰旧案重返金陵。蔺晨释放麒麟才子将至的消息，飞流随行，金陵故人和谢玉先后进入这盘棋。

### 第一集：梅岭残梦

梅长苏锻打手环，旧伤与梅岭往事伴随火光浮现。飞流关切守候；山道上蔺晨以铜制机关向誉王示意人才将至。琅琊阁书信送达，梅长苏携短刀踏上出山之路。

### 第二集：金陵城门

“苏哲”铜牌标记新身份。梅长苏与飞流进入金陵，萧景睿、言豫津相迎，霓凰对旧人产生似曾相识之感。宁国侯府“护国柱石”匾额与谢玉的军功成为下一场交锋的引线。

### 第三集：护国柱石

谢玉锻刀的回忆与侯府会面交叉，映照军功背后的血色。梅长苏以言语试探，谢玉暗中防备。夜色中，梅长苏与飞流面对更快到来的杀机，入局之势已成。

## 剧二《琅琊阁-锦囊令》

金陵赈粮将赴灾区，有人伪造两封消息，诱使靖王与江左盟在青石渡冲突，以掩盖官粮亏空。梅长苏联合飞流、蔺晨、靖王，借不同锦囊核验信息、打造工具并救人取证。

### 第一集：七牛送令

七牛车将令牌送至 X-engineer。蔺晨说明令牌是授权凭证，锦囊各有所长。两封相互指控的消息同时出现，梅长苏对齐折痕，又发现渡口图日期涂改：有人要让两方提前一夜相遇。

关键对白：“令牌是凭证。锦囊才是本事。”“还有一样，阁里不发。”“判断。”

### 第二集：锦囊有界

辨图锦囊揭出旧桥图与现状不符，推演锦囊呈现双方相撞的危险。飞流实地带回锈断铁扣，揭出修桥记录造假。四人在 X-engineer 按需制器，实测失败后根据现场尺寸调整，准备赶在桥断前救人。

关键对白：“先认清这张图，再算怎么走。”“方法没错。尺寸错了。”

### 第三集：同令不同局

靖王阻止双方接战，飞流以护腕引绳救出守账老吏，众人配合带回账箱，蔺晨救护。老吏证实印章虽真，信件却非本人所写；原件封存，案件进入查证。众人归坊，理解决定结果的不只是工具，更是选择和判断。

关键对白：“只要我们急着证明自己是对的，便会替他们把局走完。”“合用的。”“还有，用它的人。”

## 品牌表达

琅琊阁映射七牛云 MaaS 的能力汇聚；不同锦囊映射各有所长的模型；令牌映射 API Key；X-engineer 是把能力转化为实际工具的锻造场所。以上为故事隐喻，不把锦囊写成无条件预知未来的神力。

本页为基于 Canvas 项目的故事与分集整理。平台完整剧本保存在 production 下；成片剪辑可能压缩对白或调整片尾，实际交付以六集视频为准。
