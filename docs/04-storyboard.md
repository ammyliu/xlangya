# 分镜与视听设计

| 重点镜头 | 叙事作用 | 制作取舍 |
| --- | --- | --- |
| 梅长苏锻手环 | 将旧伤、身份与重新入局连接 | 炉火、手环、人物近景交替 |
| 苏哲铜牌与金陵城门 | 交代身份转换与入京 | 道具特写接环境全景 |
| 谢玉锻刀与侯府试探 | 对照军功和旧案 | 锻造意象与文戏组合 |
| 七牛车送令 | 建立品牌记忆点和授权事件 | 横构图、前四后三设定，降低复杂运动 |
| 案上双信、旧图、棋盘 | 让信息错配可视化 | 复用工坊，特写交代关键证据 |
| 工坊制器与试力 | 表达按需选用和验证 | 一镜一个主要动作，减少多人同步操作 |
| 渡口救人与账箱 | 完成线索回收 | 用引绳、接应、救护分工推进情节 |

以角色参考资产统一服装、发型和面部特征，以主要场景复用维持空间连续。字幕、首次出场姓名和地点标注在后期统一排版。古风片尾承接故事情绪，同时保留品牌署名。

对生成中出现的多余人物和异常手部，采用局部近景裁切修整，避免为可修复镜头追加生成开支。
