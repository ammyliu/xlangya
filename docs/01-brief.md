# 任务要求与验收

## 公司要求

在 Canvas 创作 3 集互相关联的短剧，每集 2—3 分钟。允许《琅琊榜》世界观衍生原创，不要求复刻第一集。作品须自然植入产品营销内容；实体商品是推荐方向，不是强制要求。交付 3 集正片与积分使用总额。

评审维度：内容质量（世界观关联、叙事连贯、画面质感、植入融合）与单位时长算力成本。不能以拖长静帧或片头来降低表面成本。

## 已确定创作约束

- 使用梅长苏、飞流、蔺晨、靖王等原作人物；人物性格与能力保持一致。
- 梅长苏仍是病弱谋士，不能通过锻造恢复武功。
- 所有主要人物在 X-engineer 亲手制作或改良各自的器具；谋士的“武器”可以是推演棋盘。
- 琅琊阁汇集模型能力；锦囊各有专长；令牌负责授权，不等于能力本身。
- 锦囊依据输入推演可能结果，不是无所不知，也不能替代人的判断和证据核验。
- 七头牛四前、三后牵引木车；优先停稳全景，不做复杂行进或飞天。
- 沿用 Canvas 现有飞流与工坊资产，避免重复生成。
