## 2 作品分析和故事创作
团队仔细研读项目要求，确认最初需求为使用公司 Canvas 制作《琅琊榜》第一集。到明确为三集连续原创短剧，每集 2—3 分钟，并同时考核内容与每分钟成本。
团队形成了两个剧本方向的创作，剧本一《麒麟才子》、剧本二《琅琊阁-锦囊令》。

## 3 《麒麟才子》剧本设定
人物依托琅琊榜的世界观，采用原有的人物设定。化名苏哲的梅长苏，十二年前梅岭劫后余生，隐匿于 X-engineer 锻造坊，靠锻打赤焰军手环压制旧伤。为翻赤焰旧案，他联合琅琊阁谋划重回金陵：蔺晨借铜制小机关向誉王放出麒麟才子将至的信号，飞流送来琅琊阁书信，梅长苏携未开刃短刀动身入京。

## 4 《琅琊阁-锦囊令》剧本设定
人物依托琅琊榜的世界观，采用原有的人物设定。所有人物在 X-engineer 锻造武器、提升能力；琅琊阁对应 MaaS，锦囊对应模型，令牌对应 API Key。大梁朝堂、赤焰冤案、江左盟与琅琊阁关系；确定梅长苏以谋略行动，飞流单纯护主，靖王坚持公道，蔺晨以医术与情报支持。形成《一纸孤证》：假信引靖王救人，原作人物协作识破圈套。

## 6 小样范围收缩
原计划验证七牛全景、梅长苏近景、锻造动作三个镜头。用户因剩余积分有限，将范围缩减为七牛车停在 X-engineer 门前、飞流观看的单镜头。决定先检查静态分镜，再考虑图生视频。
