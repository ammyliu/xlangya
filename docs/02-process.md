# 项目创作与制作流程

## 团队协作

队长王健负责视频制作；张袁昊负责剧本制作和创意设定；刘彩菊负责视频制作和后期制作。团队围绕故事、视听和成本三条主线完成两部三集作品。

## 故事开发

《麒麟才子》从“重铸自身”切入：梅长苏在 X-engineer 重锻手环，以苏哲之名重入金陵，最后与谢玉试探交锋。手环、铜牌和刀既是道具，也是身份与权力的线索。

《琅琊阁-锦囊令》以两封措辞相同的假信制造悬念。人物先核实消息，再辨图推演，继而锻造工具，最终救人留证。三集形成“起疑—验证—破局”的因果链。七牛车送令建立品牌记忆点，令牌和锦囊的使用推动情节，避免在人物对白中堆叠产品说明。

## Canvas 资产与分镜

分别建立「麒麟才子」与「xlangya」创作项目，完成剧本、角色、道具、场景与分镜组织。梅长苏以谋略主导，飞流负责行动，蔺晨提供情报和医术，靖王承担秩序与查证职责。梅长苏与苏哲保持同一人物身份与外观关联；X-engineer 只作为场所，不新增工坊主人。

以既有角色和场景资产为基础配置镜头，复用工坊、山道与渡口环境。分镜优先明确人物数量、站位、景别和单一动作；七牛车采用前四后三的横向构图设定，减少复杂转弯和大范围行进。角色一致性以参考资产、服装及发型约束，并辅以后期检查。

## 视频生成与成本控制

Canvas 完成视频生成及分集导出。《锦囊令》采用 Seedance 2.0-mini 480p 带声音方案，以约两分钟一集完成连续叙事。将预算优先分配给剧情核心镜头，减少重复动作和无效停顿；文字包装在本地后期制作，避免为字体和字幕反复生成画面。

## 后期与成片

《麒麟才子》按《梅岭残梦》《金陵城门》《护国柱石》切分，保留对白与原幕次标题，删除剧情结束后的角色、道具和场景展示。

《锦囊令》统一片头与片尾，添加对白字幕及人物、地点首次出场标注。人物名使用靠近人物的竖排宋体；片尾采用“万法归阁，各展所长”“锦囊有道，执令在人”，辅以七牛云 MaaS 品牌落款。针对重复人物和手部畸形镜头，使用局部重构图修整，保持声音与时长连续。

最终成片完成全片解码检查，并通过关键帧、切点及字幕核对确认交付。六个 MP4 分别命名、登记时长和 SHA-256，便于作品查看与文件核验。
