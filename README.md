## 创作设计

- **麒麟才子：锻器亦锻心。** 用赤焰军手环、苏哲铜牌、谢玉之刀贯穿身份转换与权谋试探；X-engineer 是人物锻造武器、蓄力入局的场所。
- **琅琊阁-锦囊令：借百家之智，守自己的判断。** 琅琊阁对应 MaaS 平台，锦囊对应不同模型，令牌对应 API Key。通过取囊、辨图、推演、制器和救人体现“各有所长、按需选用”，将品牌信息放入剧情行动。
- **制作策略。** 复用角色及场景资产，以固定构图、人物近景和道具特写控制复杂动作；Canvas 负责生成，字幕与包装在本地后期完成，降低重复生成成本。

2026-10-26 核对 Canvas 项目页面。以上是整个项目的累计消耗，包含资产、测试与生成等开支；本地分集和后期未新增 Canvas 积分。40,148 是总额度扣除上述两项目的差额，不冒充全账户实时余额。详见[积分与交付统计](docs/05-cost-and-delivery.md)。
